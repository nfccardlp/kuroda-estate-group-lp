# KURODA ESTATE GROUP — LP

黒田 慶一 / 不動産グループ代表 ランディングページ

## 構成

- `index.html` — メインLP
- `style.css` — スタイル（Dark × Gold テーマ）
- `script.js` — インタラクション全般

## 特徴

- オープニングアニメーション（ビル建築 + ゴールドライン演出）
- カスタムカーソル（デスクトップ）
- ジグザグスクロールレイアウト（左右交互セクション）
- スクロール連動ヒーロービジネス棟イラスト（SVG）
- 数字カウンターアニメーション
- 水平スクロール（得意領域カード）
- IntersectionObserver によるスクロール出現アニメーション
- フローティング LINE ボタン
- モバイル対応

## カスタマイズ

- LINE URL: `index.html` 内の `https://line.me/ti/p/PLACEHOLDER` を実際のURLに変更
- メールアドレス: `info@kuroda-estate.jp` を実際のものに変更
- プロフィール写真: `.about-avatar` を `<img>` タグに差し替え

## デプロイ

Cloudflare Pages / Vercel / GitHub Pages いずれも対応。
静的ファイルのみで動作。
